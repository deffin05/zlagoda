# Злагода

Веб-застосунок призначений для керуванням роботи міні-супермаркету. 
Дозволяє відслідковувати кількість товарів в наявності, історію збуту 
товарів, карти клієнтів та інформацію про співробітників.

## Як запустити проєкт
1. Створити та активувати віртуальне оточення Python.
2. Скачати залежності
```bash
pip install -r requirements.txt
```
3. Створити файл `.env` за шаблоном у `.env.example`. 
Отримати унікальний секретний ключ можна за допомогою:
```bash
python -c 'import secrets; print(secrets.token_hex())'
```
4. Ініціалізувати базу даних
```bash
flask init-db
```
5. Створити користувача менеджера, щоб могти зайти в систему.
```bash
flask create-user
```
6. Запустити
```bash
flask run
```
